A fast drop-in replacement for csv-reader 1.0.0: it reads broken CSV files — unterminated quotes, stray CRs, junk after closing quotes, ragged rows — exactly as the reference does, only faster, by searching for delimiters with native indexOf scans instead of reading one character at a time.

## Run it

```sh
mkdir -p output && MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
